# Fotoğraf ekleme

Fotoğrafları bu klasöre JPG, JPEG, PNG, WebP veya AVIF olarak yükleyin. GitHub
Pages yayını galeri listesini otomatik oluşturur.

Önerilen dosya adı: `2026-09-16-ankara-gecesi.jpg`. Tarihle başlayan adlar
galerinin sırasını belirlemeyi kolaylaştırır.

Başlık, yer veya tarih eklemek isterseniz `details.json` dosyasını şöyle
düzenleyin:

```json
{
  "2026-09-16-ankara-gecesi.jpg": {
    "title": "Ankara Gecesi",
    "location": "Ankara",
    "date": "Eylül 2026",
    "alt": "Gece ışıkları altında Ankara sokakları"
  }
}
```
